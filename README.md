# Humane Society Animal Shelter Management System

A management system for an animal shelter called Humane Society. This program manages a list of pets, donations, and volunteers. This program is written with Python and uses Tkinter for the GUI. Data edited/added in the GUI is written to a json file called shelter_data.json. This file holds all of the pet, donation, and volunteer data, and can be edited to reflect in the GUI.

# Runs with the command:
python3 shelter.py
